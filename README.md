# Практика 23ИС-28 — Органическая химия

## Описание работы
Выполнение практических занятий по созданию базы данных, извлечению данных через Python и выводу их в интерфейс Tkinter.

## Содержимое репозитория
- `console_alkanes.py` — скрипт для извлечения данных из PostgreSQL через библиотеку Psycopg 3.
- `gui_manual.py` — интерфейс Tkinter с ручным заполнением таблицы.
- `gui_database.py` — интерфейс Tkinter, загружающий данные из PostgreSQL по нажатию кнопки.

## Требования для запуска
- Python 3.10+
- PostgreSQL 17
- Библиотека `psycopg[binary]`

> Пароль от базы данных `Admin`
